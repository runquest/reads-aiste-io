Epic Games appears to have added a "Default Agentic Control" file that explains Fortnite's lobby interface to an automated testing tool or AI agent. The file could help internal bots navigate menus, understand UI behavior, and identify regressions during playtesting, though its exact purpose remains unconfirmed.
